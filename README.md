# Hiring-Agent

An AI-powered hiring platform that automates job search, resume analysis, ATS matching, interview preparation, application tracking, and recruiter workflows.

## Features

- 🎯 **AI Resume Scoring** - Category-scored evaluation with cited evidence
- 📊 **Job Description Matching** - Keyword overlap analysis
- 💻 **AI Coding Tests** - Generate and auto-evaluate coding assessments
- 🎤 **Mock Interviews** - Practice with AI-generated questions
- 📝 **Cover Letter Generator** - Customized letters for each application
- 🔍 **AI Job Search** - Live job listings scored against resume
- 🤝 **Networking Assistant** - Find recruiters and generate LinkedIn messages
- 📄 **PDF Reports** - Download detailed evaluation reports

## Tech Stack

- **Backend:** Python, Flask
- **AI:** Ollama, Google Gemini
- **PDF Processing:** PyMuPDF
- **Frontend:** HTML, CSS, JavaScript
- **Database:** JSON file storage
